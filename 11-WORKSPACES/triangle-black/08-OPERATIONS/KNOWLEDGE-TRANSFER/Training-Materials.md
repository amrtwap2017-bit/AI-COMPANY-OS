## Training Material Template

Each training material includes:
- Title
- Audience
- Learning objectives
- Step-by-step instructions
- Screenshots (with callouts)
- Practice exercises
- Quiz / assessment (for certification)

## Production Workflow

1. Content outline → COO approval
2. First draft (English) → written
3. Screenshots with callouts → created
4. Review → CTO + COO
5. Arabic translation → created
6. Final review → COO approval
7. Published → Knowledge base + shared drive
