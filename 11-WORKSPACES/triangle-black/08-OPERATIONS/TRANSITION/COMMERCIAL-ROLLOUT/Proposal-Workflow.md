## Proposal Workflow

```
Lead Qualified ──► Demo ──► Proposal Created ──► Reviewed ──► Sent ──► Follow-up ──► Close
     │             │          │                    │           │         │            │
  BANT met      Product    Fill template         COO        Email    Call in     Win /
  + needs       demo       + pricing             review     to       3 days      Loss
  understood               + T&Cs                (if >                 tracked
                                                   $500/mo)
```

## Proposal Template Fields

| Section | Fields | Source |
|---------|--------|--------|
| Customer info | Hotel name, contact, address | Sales notes |
| Needs | Pain points, requirements | Demo notes |
| Solution | Modules selected, integrations | Product catalog |
| Pricing | Tiers + add-ons + setup | Pricing sheet |
| Timeline | Onboarding schedule | Standard |
| Terms | Contract length, payment, SLA | Standard |
| Signatures | Both parties | Standard |

## Proposal Types

| Type | Complexity | Turnaround | Approval |
|------|-----------|------------|----------|
| Quick Quote | Low | 1 hour | Self-service |
| Standard | Medium | 1 day | COO (if < $500/mo) |
| Enterprise | High | 3 days | COO + CTO |
