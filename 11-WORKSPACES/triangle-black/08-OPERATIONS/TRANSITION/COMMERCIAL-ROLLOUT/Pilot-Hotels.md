# 08 — Pilot Hotels

> Pilot hotel program for initial customer acquisition.

| Source | File | Input |
|--------|------|-------|

## Pilot Program Structure

| Element | Detail |
|---------|--------|
| Duration | 3 months |
| Discount | 50% off standard pricing |
| Hotels | Maximum 5 |
| Support | Dedicated (direct to CTO + COO) |
| Feedback | Weekly check-in calls |
| Exit | Convert to paid or end at month 3 |

## Pilot Hotel Selection Criteria

| Criterion | Weight | Requirement |
|-----------|--------|-------------|
| Willingness to provide feedback | High | Must commit to weekly calls |
| Active daily use | High | Must use platform daily |
| Hotel size | Medium | < 100 rooms preferred |
| Location | Medium | Cairo area (onsite support) |
| Technical capability | Low | Basic computer literacy |
| Contract flexibility | Low | Month-to-month |

## Pilot Hotel Onboarding

| Week | Activity | Owner |
|------|----------|-------|
| Week 0 | Contract signed, welcome call | COO |
| Week 1 | Tenant provisioned, data migration | DevOps |
| Week 2 | Admin training, staff training | Support |
| Week 3 | Go-live, hypercare begins | DevOps + Support |
| Week 4 | First check-in, feedback review | COO |
| Week 8 | Mid-pilot review | COO + CTO |
| Week 12 | Pilot conclusion, conversion decision | COO |

## Pilot Success Criteria

| Metric | Target |
|--------|--------|
| Daily active usage | > 5 days/week |
| Staff trained | > 80% of staff |
| Reservations processed | > 10/week |
| Customer satisfaction | > 4.0/5 |
| Feedback provided | Weekly |
| Feature requests logged | At least 3 |

## Pilot Conversion

| Outcome | Action |
|---------|--------|
| Successful pilot | Offer standard pricing, 10% loyalty discount |
| Partial success | Extended pilot (1 month) with targeted support |
| Unsuccessful | Polite exit, collect final feedback |
| Customer declines | Understand reasons, document learnings |
