## Executive Approval Form

```
─────────────────────────────────────────────
EXECUTIVE APPROVAL — [GATE NAME]
─────────────────────────────────────────────

Date: _____________

I confirm that the criteria for [GATE NAME] have been met:

[ ] Readiness scores meet minimum thresholds
[ ] Risks reviewed and accepted
[ ] All dependencies resolved
[ ] Team confirms readiness
[ ] Documentation is complete

Decision:
[ ] APPROVED — Proceed to next phase
[ ] CONDITIONAL — Proceed with conditions (see below)
[ ] DENIED — Return for remediation

Conditions (if applicable):
_______________________________________________

Signatures:

CTO: _____________________ Date: _____________
COO: _____________________ Date: _____________
CEO: _____________________ Date: _____________
```

## Approval Records

All approvals are recorded in:
- Decision register (Decision-Matrix.md)
- Executive Dashboard (EXECUTIVE-DASHBOARD.md)
- Transition report (12-TRANSITION-CLOSURE)

## Conditional Approvals

If a gate is conditionally approved:
1. Conditions are documented explicitly
2. Owner assigned for each condition
3. Deadline set for resolution
4. Conditions tracked in program status
5. Resolution verified before next gate
