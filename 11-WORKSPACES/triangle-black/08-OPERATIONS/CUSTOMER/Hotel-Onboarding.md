## Hotel Setup Checklist

- [ ] Hotel profile created (name, address, contact)
- [ ] Room types configured (Standard, Deluxe, Suite, etc.)
- [ ] Room inventory loaded (room numbers, floor, category)
- [ ] Rate plans configured (BAR, corporate, group, promo)
- [ ] Amenities and services configured
- [ ] Housekeeping schedule defined (clean types, frequency)
- [ ] Restaurant / F&B menus loaded (if applicable)
- [ ] POS integration configured (if applicable)
- [ ] Payment gateway configured (if applicable)
- [ ] Tax rates configured (VAT, tourism tax, etc.)
- [ ] Currency configured
- [ ] Language preferences set (Arabic, English)
- [ ] Notification preferences defined (SMS, email, in-app)
- [ ] Custom fields configured (if needed)
- [ ] User roles created (front desk, housekeeping, manager)

## Hotel Onboarding Timeline

| Step | Duration | Owner |
|------|----------|-------|
| Hotel profile creation | 1 hour | Support |
| Room and rate configuration | 2-3 hours | Support + Hotel |
| Integration setup | 4-8 hours | DevOps |
| Training (hotel staff) | 2 hours | Support |
| Validation and go-live | 1 hour | Support |
