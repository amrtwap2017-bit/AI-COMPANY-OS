## Support Tiers

| Tier | Handler | Scope | Channels |
|------|---------|-------|----------|
| Tier 1 | Support Agent | Password reset, basic how-to, status check | Email, chat, phone |
| Tier 2 | Senior Support | Bug reports, configuration issues | Email, phone |
| Tier 3 | DevOps / Engineering | Complex technical issues, code bugs | Slack, phone |
| Tier 4 | CTO / COO | Escalation, account issues | Phone, in-person |
