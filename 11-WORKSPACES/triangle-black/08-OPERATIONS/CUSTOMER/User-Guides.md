## Guide Format

Each guide follows this structure:
1. **Overview** — What this guide covers
2. **Prerequisites** — What the user needs
3. **Step-by-Step Instructions** — Screenshots + numbered steps
4. **Tips and Best Practices**
5. **Troubleshooting** — Common issues
6. **Related Guides**

## Language

- All guides in English and Arabic
- Screenshots with Arabic UI when available
- Technical terms explained in both languages
