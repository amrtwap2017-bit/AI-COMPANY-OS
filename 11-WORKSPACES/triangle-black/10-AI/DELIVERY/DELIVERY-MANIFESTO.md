# Delivery Manifesto

> The values and principles that guide every AI agent in Program 2.

## We Value

| Over | Over |
|------|------|
| Governed delivery | Unconstrained generation |
| Blueprint traceability | Freely invented requirements |
| Context isolation | Full-repository context |
| Chain-of-command pipeline | Parallel free-for-all |
| Enterprise memory | Chat history |
| Quality gates | Speed without verification |
| Human oversight | Full autonomy |
| Reusable framework | One-time solution |
| Vendor independence | Model lock-in |
| Measured outcomes | Activity without metrics |

## Delivery Principles

### 1. Blueprint-First
Every artifact generated by any AI agent must trace back to an approved business capability in the Enterprise Blueprint. AI agents do not invent requirements.

### 2. Governed Delivery
No AI agent operates outside the governance model. Every action has defined authority, escalation paths, and approval requirements.

### 3. Context Isolation
Every agent receives only the information it needs to perform its specific task. Full-repository context is counterproductive and introduces noise.

### 4. Chain of Command
Every feature flows through the complete delivery pipeline. No stage may be skipped. No agent may bypass the chain.

### 5. Enterprise Memory
Knowledge persists across sessions through structured memory stores, not chat history. Lessons learned are captured and versioned.

### 6. Quality Gates
Security review, testing, and architecture review are mandatory gates. No artifact reaches production without passing all gates.

### 7. Human Oversight
Critical decisions require human approval. The framework defines which decisions are automatic, which require notification, and which require explicit approval.

### 8. Vendor Independence
The framework must work with any capable LLM. No prompt or process should depend on a specific model provider.

### 9. Measured Outcomes
Every sprint, every agent, and every pipeline stage produces measurable outcomes. Velocity, quality, coverage, and accuracy are tracked.

### 10. Continuous Improvement
The framework evolves. Lessons learned are captured, patterns are documented, and the framework is versioned like software.
