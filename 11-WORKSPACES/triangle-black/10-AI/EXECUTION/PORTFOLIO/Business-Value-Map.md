# Business Value Map

## Overview

The Business Value Map is the framework for quantifying, tracking, and reporting the value delivered by portfolio investments. It ensures that every program has a clear value hypothesis, measurable value drivers, and a mechanism for validating whether anticipated benefits are realized.

The value map transforms abstract strategic objectives into concrete, measurable value dimensions that can be tracked from program inception through post-completion benefits realization.

## Value Dimensions

Value is assessed across five primary dimensions. Each program may contribute to one or more dimensions:

| Dimension | Description | Typical Metrics |
|-----------|-------------|-----------------|
| **Revenue** | Direct and indirect revenue generation | New revenue ($), revenue uplift (%), customer acquisition, market share |
| **Cost** | Cost reduction and avoidance | Cost savings ($), cost avoidance ($), efficiency ratio, unit cost reduction |
| **Risk** | Risk reduction and mitigation | Risk exposure reduction ($), compliance gap closure, audit findings resolved |
| **Compliance** | Regulatory and policy adherence | Regulatory obligations met, certification attainment, penalty avoidance |
| **Customer Satisfaction** | Customer experience and satisfaction improvement | Net Promoter Score (NPS), Customer Satisfaction (CSAT), Customer Effort Score (CES) |

### Value Dimension Weighting

Each program assigns weights to value dimensions based on strategic alignment:

| Dimension | Weight | Rationale |
|-----------|--------|-----------|
| Revenue | 30% | Primary growth objective |
| Cost | 20% | Operational efficiency target |
| Risk | 20% | Regulatory environment |
| Compliance | 15% | Mandatory requirements |
| Customer Satisfaction | 15% | Experience transformation |

Weights sum to 100% for each program and are established during the program definition phase.

## Value Scoring Model

The value scoring model provides a standardized method for evaluating and comparing initiatives:

### Value Score Formula

```
Value Score = Σ (Dimension Score × Dimension Weight)
```

Where:
- **Dimension Score** = Normalized score (0-100) for each value dimension
- **Dimension Weight** = Importance weight assigned to that dimension

### Dimension Score Calculation

Each dimension is scored based on the program's projected or actual contribution:

| Score Range | Rating | Description |
|-------------|--------|-------------|
| 81-100 | Transformational | Step-change improvement, industry-leading impact |
| 61-80 | Significant | Major improvement, clear competitive advantage |
| 41-60 | Moderate | Measurable improvement, noticeable business impact |
| 21-40 | Incremental | Marginal improvement, limited business impact |
| 0-20 | Minimal | Negligible or indirect contribution |

### Scoring Guidelines by Dimension

**Revenue Scoring:**
- 100: >$50M new annual revenue or >20% market share gain
- 75: $10M-$50M new annual revenue or 10-20% market share gain
- 50: $1M-$10M new annual revenue or 5-10% market share gain
- 25: <$1M new annual revenue or <5% market share gain

**Cost Scoring:**
- 100: >$20M annual cost savings or >30% efficiency gain
- 75: $5M-$20M annual cost savings or 15-30% efficiency gain
- 50: $500K-$5M annual cost savings or 5-15% efficiency gain
- 25: <$500K annual cost savings or <5% efficiency gain

**Risk Scoring:**
- 100: Eliminates critical risk exposure >$50M
- 75: Significantly reduces risk exposure $10M-$50M
- 50: Moderately reduces risk exposure $1M-$10M
- 25: Marginally reduces risk exposure <$1M

**Compliance Scoring:**
- 100: Full compliance with all applicable regulations
- 75: Major compliance gaps closed, no material findings
- 50: Moderate compliance improvement, some gaps remain
- 25: Minor compliance improvement

**Customer Satisfaction Scoring:**
- 100: NPS/CSAT improvement >20 points
- 75: NPS/CSAT improvement 10-20 points
- 50: NPS/CSAT improvement 5-10 points
- 25: NPS/CSAT improvement <5 points

## Value Realization Tracking

Value realization is the process of measuring and confirming that anticipated benefits are actually delivered. Tracking occurs throughout the program lifecycle and continues after program closure.

### Value Realization Stages

| Stage | Timing | Activity |
|-------|--------|----------|
| **Baseline** | Program definition | Establish current-state metrics for each value dimension |
| **Target Setting** | Program planning | Define target values, measurement method, and timing |
| **In-Flight Tracking** | Program execution | Measure interim value indicators, track leading metrics |
| **Realization Assessment** | Program close | Measure achieved value against targets |
| **Sustained Measurement** | Post-close (6-12 months) | Confirm value is sustained, capture ongoing benefits |

## Value Governance

| Role | Responsibility |
|------|----------------|
| Value Architect | Defines value models, validates measurement approach, advises programs |
| Program Manager | Owns value realization plan, tracks in-flight metrics, reports progress |
| Portfolio Manager | Aggregates value across programs, reports portfolio-level value |
| Finance | Validates financial value claims, provides baseline data |
| Sponsor | Accountable for value realization, approves value target changes |

## Value Optimization

Value optimization involves actively managing the portfolio to maximize value delivery:

1. **Value profiling** at program initiation ensures all programs have clear, measurable value targets.
2. **Value reviews** at portfolio governance checkpoints surface underperforming programs for remediation or termination.
3. **Value rebalancing** reallocates investment from low-value to high-value initiatives.
4. **Value assurance** validates that claimed value is real and sustainable.
5. **Value lessons** capture what worked and what did not to improve future value forecasting.
