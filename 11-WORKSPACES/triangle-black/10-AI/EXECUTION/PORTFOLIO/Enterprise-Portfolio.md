# Enterprise Portfolio Definition

## Purpose

The Enterprise Portfolio is the top-level construct for organizing all strategic investments across the organization. It provides a unified view of programs, projects, and initiatives, enabling leadership to optimize resource allocation, balance risk, and maximize value realization against enterprise strategic objectives.

## Strategic Alignment Model

The enterprise portfolio ensures every investment connects to enterprise strategy through a structured alignment model:

```
Enterprise Strategy
    ├── Vision & Mission
    ├── Strategic Pillars (3-5 year)
    │   ├── Growth
    │   ├── Operational Excellence
    │   ├── Customer Experience
    │   └── Innovation
    ├── Strategic Objectives (1-3 year)
    │   ├── Objective A → Portfolio 1
    │   ├── Objective B → Portfolio 2
    │   └── Objective C → Portfolio 3
    └── Key Results (quarterly)
        ├── KR 1.1 → Program A
        ├── KR 1.2 → Program B
        └── KR 2.1 → Program C
```

Each strategic objective is owned by an executive sponsor. Portfolios are created or retired based on strategic priorities. Programs within portfolios are directly mapped to key results.

## Portfolio Structure

The enterprise portfolio is structured by strategic domain, not by organizational hierarchy. This prevents siloed thinking and ensures cross-functional collaboration. The standard portfolio structure includes:

- **Portfolio ID:** Unique identifier (e.g., PORT-001)
- **Portfolio Name:** Descriptive business name
- **Strategic Objective(s):** The objective(s) this portfolio serves
- **Portfolio Sponsor:** Executive accountable for outcomes
- **Portfolio Manager:** Day-to-day operational owner
- **Programs:** List of programs within the portfolio
- **Total Investment:** Allocated budget across all programs
- **Time Horizon:** Expected duration (typically 1-3 years)
- **Status:** Active, On-Hold, Completed, Retired

## Initiative Classification

All initiatives within the portfolio are classified by their primary strategic intent. This classification drives evaluation criteria, funding models, and governance treatment:

| Classification | Description | Evaluation Criteria | Funding Model |
|----------------|-------------|-------------------|---------------|
| **Growth** | Revenue-generating, market-expanding, customer-acquiring | Revenue potential, market share, customer lifetime value | Growth capital, outcome-based |
| **Efficiency** | Cost-reducing, productivity-enhancing, process-optimizing | Cost savings, productivity gain, cycle time reduction | Operational budget, cost-center |
| **Compliance** | Regulatory, legal, security, audit-mandated | Risk reduction, penalty avoidance, certification attainment | Mandatory allocation, fixed |
| **Innovation** | Experimental, emerging technology, new business model | Strategic option value, learning, IP creation | Innovation fund, stage-gated |

Initiatives may span multiple classifications, but a primary classification is assigned for governance purposes.

## Portfolio Lifecycle

### 1. Define

The portfolio definition phase establishes the strategic context and scope. Activities include:

- Reviewing and refreshing enterprise strategic objectives
- Conducting environmental scans (market, technology, regulatory)
- Assessing current portfolio composition and performance
- Identifying capability gaps and strategic opportunities
- Defining portfolio boundaries and constraints

### 2. Prioritize

During prioritization, proposed initiatives are evaluated and ranked:

- Initiative proposals are submitted with business cases
- Each proposal is scored using the initiative scoring model (strategic fit, value, feasibility, risk)
- Cross-portfolio dependencies are identified and assessed
- A ranked backlog of initiatives is produced
- Investment scenarios are modeled (optimistic, baseline, conservative)

### 3. Approve

Approval is the formal commitment of resources:

- Portfolio Review Board evaluates the prioritized backlog
- Funding allocations are approved per program
- Program charters are signed by the sponsor
- Resource pools are committed
- Governance cadence is established
- Decision is recorded in the portfolio decision log

### 4. Execute

Execution involves active portfolio oversight:

- Programs operate under their charters with defined milestones
- Portfolio Manager tracks progress against KPIs
- Monthly investment reviews assess budget burn and value delivery
- Quarterly strategic reviews evaluate objective attainment
- Risks and issues are managed at portfolio level
- Rebalancing decisions are made as needed

### 5. Review

The review phase closes the loop and informs the next cycle:

- Portfolio performance is assessed against strategic objectives
- Value realization is measured and reported
- Lessons learned are documented and shared
- Portfolio structure is assessed for continued relevance
- Recommendations are made for the next planning cycle
- Portfolio closure or transition is executed if applicable

## Portfolio Governance Artifacts

| Artifact | Description | Cadence |
|----------|-------------|---------|
| Portfolio Charter | Defines portfolio scope, objectives, and governance | Annually |
| Portfolio Dashboard | KPIs, health metrics, risk indicators | Weekly/Monthly |
| Investment Review Report | Budget vs actual, ROI, value realization | Monthly |
| Strategic Alignment Report | Objective progress mapping | Quarterly |
| Portfolio Decision Log | Key decisions and rationale | Continuous |
| Portfolio Health Check | Holistic assessment of portfolio performance | Quarterly |
