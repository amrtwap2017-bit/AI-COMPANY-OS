## Key Definitions

| Term | Definition |
|------|------------|
| Portfolio | Collection of programs aligned to strategic objectives |
| Program | Group of related epics delivering a business capability |
| Epic | Large body of work spanning multiple sprints |
| Feature | Specific functionality within an epic |
| Story | Smallest unit of customer-valuable work |
| Task | Engineering unit of work assigned to an AI agent |
| Sprint | Time-boxed delivery cycle (2 weeks) |
| Deliverable Contract | Standardized output every task must produce |
| Quality Gate | Mandatory checkpoint an artifact must pass |
