# Epic Management

## Overview

Epic Management provides the framework for managing large-scale work initiatives that span multiple sprints and involve cross-functional teams. An epic represents a significant body of work that delivers measurable business value and aligns with strategic objectives defined in the Enterprise Blueprint (Program 1).

## Epic Lifecycle

The epic lifecycle consists of seven stages:

1. **Identify** — Epics are identified through strategic planning, stakeholder input, capability gaps, or market demands. Epic candidates are logged in the Epic Catalog.
2. **Define** — Each epic candidate is refined with a clear description, scope, acceptance criteria, and value proposition using the Epic Template.
3. **Prioritize** — Epics are scored against business value, effort, dependency, risk, and strategic alignment using the prioritization framework.
4. **Approve** — Approved epics enter the execution pipeline with allocated budget, resources, and timeline.
5. **Execute** — Epics are decomposed into features and user stories, tracked through sprints, with regular progress reviews.
6. **Accept** — Completed epics undergo acceptance review against Definition of Done and stakeholder sign-off.
7. **Close** — Closed epics are archived, value realization is measured, and lessons learned are captured.

## Epic Roles

| Role | Responsibility |
|------|---------------|
| **Epic Owner** | Accountable for epic definition, value delivery, and stakeholder communication |
| **Program Manager** | Governs epic prioritization, dependency management, and cross-epic coordination |
| **Product Owner** | Ensures epic aligns with product roadmap and decomposes into features |
| **Technical Lead** | Provides technical feasibility assessment and architectural guidance |
| **Delivery Lead** | Tracks execution progress, manages risks, and reports metrics |
| **Stakeholder** | Provides input on value, reviews progress, and signs off on completion |

## Governance

Epics are governed through a structured review cadence:

- **Weekly Epic Sync** — Status updates, blocker resolution, and cross-epic dependency checks
- **Monthly Epic Review** — Progress against milestones, metric review, and reprioritization decisions
- **Quarterly Epic Planning** — Strategic alignment check, new epic intake, and portfolio rebalancing
- **Epic Acceptance Board** — Formal acceptance review with stakeholder sign-off

## Integration with Program Management

Epic Management operates within the Program 3 (Enterprise AI Execution System) framework and traces to:

- **Program 1 (Enterprise Blueprint)** — Each epic maps to one or more business capabilities defined in the blueprint
- **Feature Management** — Epics decompose into features managed through the Feature Management framework
- **Release Management** — Epics are delivered across releases with defined milestones
- **Portfolio Management** — Epic portfolio is managed for value optimization and resource balancing

## Key Principles

- **Value-Driven** — Every epic must articulate clear business value with measurable outcomes
- **Outcome-Focused** — Success is measured by realized value, not output volume
- **Transparent** — Epic status, progress, and decisions are visible to all stakeholders
- **Adaptive** — Epics can be reprioritized based on changing business needs
- **Traceable** — Every epic traces to strategic objectives, capabilities, and delivered features
