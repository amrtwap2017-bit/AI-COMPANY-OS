# Client Portal Strategy

## Philosophy

**The portal is not a feature. It is the product.**

The client portal is the single most visible manifestation of Triangle Black's value proposition. In an industry where vendors are judged by their responsiveness and transparency, the portal is the permanent, always-on proof point that Triangle Black operates differently.

## Strategic Objectives

1. **Transparency** — Clients see exactly what we see: project status, quotation details, document history
2. **Stickiness** — Once a hotel team uses the portal daily, switching costs become prohibitive
3. **Reduced Friction** — Clients self-serve on quotations, documents, and requests instead of emailing
4. **Value Demonstration** — Dashboards and reports in the portal justify the partnership retainer
5. **Data Collection** — Portal usage reveals client priorities, pain points, and engagement patterns

## Design Principles

| Principle | Application |
|-----------|-------------|
| Mobile-first | Field staff access portal from phones; responsive design mandatory |
| Read-optimized | Clients mostly consume information; creation is guided and structured |
| Low cognitive load | Hotel staff manage 20+ vendors; our portal must be the simplest to use |
| Branded per client | Portal shows client logo, name, and color; they feel it's their space |
| Notification-rich | Proactive alerts (new quote, status change, document) drive return visits |

## V1 Portal Scope

### Client-Facing Features

- Secure login with email/password and magic link option
- Dashboard: active projects, recent quotations, pending requests
- Projects: view project list, milestone progress, deliverables
- Quotations: view quotation history, download PDFs, approve/reject
- Documents: file repository organized by project and category
- Requests: submit new service request or RFQ
- Profile: update contact details, notification preferences

### Internal-Only Features (Supporting the Portal)

- Request management dashboard (internal team)
- Document upload and categorization
- Quotation publishing workflow
- Portal activity log

### V1 Non-Scope

- Real-time chat/messaging
- Payment processing
- Multi-property portfolio view
- Customizable dashboards
- Self-serve report builder

## User Types in Portal

| Role | Portal Access | Primary Actions |
|------|---------------|-----------------|
| Hotel GM | Read + approve | View dashboard, approve quotations, review reports |
| Chief Engineer | Full access | Track projects, view documents, submit requests |
| Purchasing Manager | Procurement view | View quotations, download documents |
| Financial Controller | Financial view | View quotation values, approved contracts |
| Owner | Executive view | Dashboard, key metrics, document access |

## Success Metrics

| Metric | Target (V1) |
|--------|-------------|
| Client login rate (weekly) | 80%+ of assigned users |
| Self-serve rate (requests via portal vs. email) | 50%+ by month 3 |
| Portal NPS | 40+ |
| First-time login success | 95%+ |
| Quotation approval time (in portal) | < 48 hours |
