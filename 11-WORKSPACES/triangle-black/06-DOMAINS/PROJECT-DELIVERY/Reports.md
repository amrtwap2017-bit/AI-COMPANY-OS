# 02-PROJECT-DELIVERY — Reports

| Report | Frequency | Content |
|--------|-----------|---------|
| Project Status Report | Weekly | Progress %, milestones, risks, budget burn |
| Daily Site Report | Daily | Workforce, equipment, work done, issues |
| NCR Summary | Per project | All NCRs by severity, status, resolution time |
| Milestone Progress | Per project | Planned vs actual dates, approval status |
| Resource Utilization | Monthly | Hours per resource, project allocation |
| Handover Report | Per handover | Snag list, docs, training, sign-offs |
| Lessons Learned | Per project close | What went well, improvements, archive |
