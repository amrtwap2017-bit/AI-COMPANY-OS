# 02-PROJECT-DELIVERY — Roles

| Role | Description |
|------|-------------|
| PROJECT_MANAGER | Full project oversight, milestone approval, team management |
| SITE_ENGINEER | Daily reports, quality inspections, NCR creation |
| SITE_SUPERVISOR | Workforce management, timesheet approval |
| QUALITY_INSPECTOR | Inspections, NCR lifecycle, quality audits |
| SAFETY_OFFICER | Risk register, safety inspections, incident reporting |
| PROJECT_COORDINATOR | Documentation, scheduling, meeting minutes |
| CLIENT_REP | View progress, approve milestones, sign handover |
