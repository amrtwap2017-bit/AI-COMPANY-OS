# 02-PROJECT-DELIVERY — KPIs

| KPI | Formula | Target |
|-----|---------|--------|
| Schedule adherence | Milestones on time / Total milestones | ≥ 80% |
| Budget adherence | Actual cost / Budget | ≤ 100% |
| NCR closure rate | NCRs closed within SLA / Total NCRs | ≥ 90% |
| Daily report compliance | Reports submitted / Expected days | ≥ 95% |
| Handover on time | Handovers on schedule / Total | ≥ 90% |
| Project profitability | (Revenue - Cost) / Revenue × 100 | ≥ 20% |
| Safety incidents | Count per 100,000 hours | < 1 |
