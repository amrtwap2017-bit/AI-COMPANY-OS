# 02-PROJECT-DELIVERY — Acceptance Criteria

- [ ] Project auto-created when contract activated
- [ ] Milestone lifecycle: planned → in_progress → completed → approved
- [ ] Milestone approval blocked if unresolved critical NCRs exist
- [ ] Daily report can be created with workforce count, hours, work completed
- [ ] NCR lifecycle: open → in_progress → resolved → verified → closed
- [ ] Critical NCR sends notification to management
- [ ] Risk register with likelihood × impact scoring
- [ ] Handover process: snag list → docs → sign-off → project closed
- [ ] Resource calendar prevents double-booking
- [ ] Project timeline (Gantt) renders correctly
