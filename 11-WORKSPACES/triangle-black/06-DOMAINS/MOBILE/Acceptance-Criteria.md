# 12-MOBILE — Acceptance Criteria

- [ ] Field engineer can create daily report from mobile (offline-capable)
- [ ] Site survey can be captured with photos, measurements, notes
- [ ] NCR can be created from mobile with photo evidence
- [ ] Timesheet entries can be submitted from phone
- [ ] Client can approve/reject quotations from phone
- [ ] Client can view project status and contracts from phone
- [ ] Offline mode: forms work without connectivity
- [ ] Sync: changes push when connectivity restored
- [ ] Photos are geo-tagged on capture
- [ ] App works as PWA (installable, responsive)
