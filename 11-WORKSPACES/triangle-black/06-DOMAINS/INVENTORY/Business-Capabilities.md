# 05-INVENTORY — Business Capabilities

| ID | Capability | Description |
|----|-----------|-------------|
| INV-01 | Stock Receipt | Receive goods from PO (03-PROCUREMENT) |
| INV-02 | Stock Issue | Issue materials to project/site |
| INV-03 | Stock Transfer | Move stock between warehouses/sites |
| INV-04 | Stock Adjustment | Write-off, damage, return to supplier |
| INV-05 | Inventory Count | Physical count vs system reconciliation |
| INV-06 | Reorder Alerts | Low stock notification based on min levels |
| INV-07 | Inventory Valuation | Cost tracking (FIFO/weighted average) |
| INV-08 | Warehouse Management | Location, bin, zone tracking |
