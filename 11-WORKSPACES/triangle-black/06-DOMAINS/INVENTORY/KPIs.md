# 05-INVENTORY — KPIs

| KPI | Target |
|-----|--------|
| Inventory accuracy (physical vs system) | ≥ 98% |
| Stock turnover ratio | ≥ 4x/year |
| Low stock incidents per month | < 5 |
| Stock adjustment value (% of total) | < 2% |
| Inventory carrying cost | Minimized |
| Issued-to-waste ratio | ≥ 95% issued, < 5% waste |
