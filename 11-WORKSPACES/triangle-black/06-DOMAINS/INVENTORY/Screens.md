# 05-INVENTORY — Screens

| Screen | Route | Description |
|--------|-------|-------------|
| Inventory Dashboard | /inventory | Stock levels by warehouse, low stock alerts |
| Item Detail | /inventory/items/:id | Transactions, current stock, location |
| Stock Receipt | /inventory/receipt | Receive goods from PO |
| Stock Issue | /inventory/issue | Issue materials to project |
| Stock Transfer | /inventory/transfer | Move goods between warehouses |
| Stock Adjustment | /inventory/adjust | Write-off / found / return |
| Warehouse View | /inventory/warehouses | Stock by location |
| Transaction Log | /inventory/transactions | All movements with filters |
