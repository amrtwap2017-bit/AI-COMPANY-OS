# 05-INVENTORY — Reports

| Report | Frequency | Content |
|--------|-----------|---------|
| Stock Status | Weekly | All items, quantities, valuations |
| Low Stock Report | Daily | Items below reorder level |
| Stock Movement | Monthly | All transactions by period |
| Inventory Valuation | Monthly | Total stock value (weighted avg) |
| Project Consumption | Per project | Materials used vs budget |
| Count Sheet | Per count | Physical count template |
