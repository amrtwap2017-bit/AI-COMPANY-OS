# 01-COMMERCIAL — Acceptance Criteria

## Sprint 1 (MVR) — Core Pipeline

- [x] Sales rep can capture a lead from web form
- [x] Lead is auto-scored on creation
- [x] Lead status progresses: new → contacted → qualified (or disqualified)
- [x] User can create an account (company) with full profile
- [x] User can add contacts to an account
- [x] User can view pipeline as kanban by stage
- [x] Opportunity stage advances forward only

## Sprint 2 — Site Survey & Quotation

- [ ] Engineer can schedule site survey from opportunity
- [ ] Engineer can capture findings, photos, measurements
- [ ] Manager can approve/reject survey report
- [ ] User can create quotation from approved survey
- [ ] User can add line items (materials, labor, equipment)
- [ ] Margin is calculated in real-time
- [ ] Internal approval workflow works (submit → approve/reject)
- [ ] PDF quotation is generated

## Sprint 3 — Contract & Handoff

- [ ] Contract created from approved quotation
- [ ] Contract lifecycle: draft → signed → active → completed/terminated
- [ ] Contract activation auto-creates project (Phase 6)
- [ ] Variation order can be created on active contract
- [ ] Pipeline forecast displays weighted values

## Sprint 4 — Polish & Refine

- [ ] Lead scoring can be reconfigured
- [ ] Quotation templates can be customized
- [ ] Win/loss analysis report renders
- [ ] Lead conversion rate KPI shows correct data
- [ ] All events captured in audit log
- [ ] All permissions enforced by RBAC
