# 01-COMMERCIAL — Roles

| Role | Module | Description |
|------|--------|-------------|
| SALES_REP | CRM | Create leads, manage opportunities, submit quotations, view pipeline |
| SALES_MANAGER | CRM | All SALES_REP + approve quotations, reassign leads, view forecasts |
| ENGINEER | CRM | Schedule surveys, capture findings, submit reports |
| ENGINEERING_MANAGER | CRM | All ENGINEER + approve survey reports, pricing inputs |
| COMMERCIAL_ADMIN | CRM | Configure scoring rules, quotation templates, settings |
| CLIENT_VIEWER | Portal | View quotations, contracts, project status |
| CLIENT_APPROVER | Portal | CLIENT_VIEWER + approve quotations, sign contracts |
