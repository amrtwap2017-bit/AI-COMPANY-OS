# 09-EXECUTIVE-INTELLIGENCE — Business Overview

## Context

Executives need a single pane of glass across all domains. This module aggregates KPIs from 01-COMMERCIAL through 07-MAINTENANCE and presents real-time dashboards, trend analysis, and exportable reports.

## Key Dashboards

| Dashboard | Source Domains | Key Metrics |
|-----------|---------------|-------------|
| Executive Overview | All | Revenue, pipeline, projects, cash flow, margin |
| Sales Pipeline | 01-COMMERCIAL | Leads, opportunities, win rate, forecast |
| Project Portfolio | 02-PROJECT-DELIVERY | Active projects, milestone progress, NCRs |
| Financial | 06-FINANCIAL-CONTROL | Revenue, AR aging, project P&L |
| Procurement | 03-PROCUREMENT, 04-SUPPLIER | PO status, supplier performance |
| Operational | All | SLA compliance, resource utilization |
