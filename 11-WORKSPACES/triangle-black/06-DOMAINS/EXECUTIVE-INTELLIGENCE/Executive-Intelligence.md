# Phase 06 — Executive Intelligence

> Dashboards, KPIs, reports, and business intelligence.

## Domain Scope

| Capability | Description | Priority |
|------------|-------------|----------|
| Executive Dashboard | Real-time KPI overview | P1 |
| Custom Reports | Configurable report builder | P1 |
| Data Export | CSV, PDF export for all reports | P1 |
| KPI Alerts | Threshold-based notifications | P2 |

## Key Dashboards

| Dashboard | Audience | KPIs |
|-----------|----------|------|
| Executive Overview | CEO/Partner | Revenue, margin, pipeline value, active projects, cash flow |
| Sales Pipeline | Sales Manager | Leads by stage, conversion rate, average deal size |
| Project Health | Project Manager | On-time %, NCR count, milestone progress |
| Financial | Financial Controller | AR aging, AP aging, revenue recognized, DSO |
| Procurement | Procurement Officer | PO value, delivery performance, supplier rating |

## Key KPIs

| KPI | Formula | Target | Domain Source |
|-----|---------|--------|---------------|
| Lead Conversion Rate | Contracts signed / Leads created | 30%+ | Commercial |
| Average Margin | (Revenue - Cost) / Revenue | 25%+ | All domains |
| On-Time Delivery | Milestones on time / Total milestones | 90%+ | Project Delivery |
| DSO | (AR / Revenue) × Days | <45 days | Financial Control |
| NCR Rate | NCRs / Project count | <5 per project | Project Delivery |
