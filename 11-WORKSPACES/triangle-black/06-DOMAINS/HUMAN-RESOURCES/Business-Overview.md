# 13-HUMAN-RESOURCES — Business Overview

## Business Context

Hospitality engineering companies in Egypt employ 50-200+ staff across multiple disciplines: engineers, technicians, project managers, sales, procurement, and administration. Triangle Black's HR domain manages every employee interaction from hire to retirement, with tight integration to project costing and financial control.

## Value Proposition

| Stakeholder | Value |
|-------------|-------|
| Employees | Self-service leave requests, timesheets, payslip access |
| Managers | Team calendar, leave approvals, timesheet sign-off, cost visibility |
| HR Team | Employee records, org charts, attendance tracking, compliance |
| Finance | Accurate timesheet-based project cost allocation, payroll data |
| COO | Headcount budget tracking, utilization reports, turnover analytics |

## Operational Workflows

### W1: Employee Onboarding
```
Accepted offer → Create employee record → Assign department → Set up IT access → Schedule orientation
Roles: HR, IT, Manager
SLA: Complete within 3 business days of start date
```

### W2: Leave Management
```
Submit request → Manager approve/reject → Update balance → Notify team calendar
Roles: Employee, Manager
SLA: Approve/reject within 4 hours
```

### W3: Timesheet Submission
```
Weekly/daily timesheet → Log hours per project/task → Submit → Manager approve → Lock for payroll
Roles: Employee, Manager, Finance
SLA: Submit by EOD Sunday, approve by Tuesday
```

### W4: Attendance Tracking
```
Check-in → Track breaks → Check-out → Calculate hours → Flag anomalies
Roles: Employee, HR
SLA: Real-time tracking, daily anomaly review
```
