# 13-HUMAN-RESOURCES — Roles

| Role | Module | Description |
|------|--------|-------------|
| EMPLOYEE | HR | View own profile, submit leave, submit timesheets, view payslips |
| MANAGER | HR | All EMPLOYEE + approve leave, approve timesheets, view team calendar, view team cost |
| HR_ADMIN | HR | All MANAGER + create/edit employees, manage departments, configure leave policies, run reports |
| HR_MANAGER | HR | All HR_ADMIN + payroll export, headcount budget, performance reviews |
| FINANCE_HR | HR | View timesheet data for cost allocation, export payroll data, view salary info |
| SYSTEM_ADMIN | HR | Configure attendance rules, leave policy templates, system-wide HR settings |
