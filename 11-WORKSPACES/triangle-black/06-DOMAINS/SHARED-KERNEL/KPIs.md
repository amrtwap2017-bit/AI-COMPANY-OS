# 00-SHARED-KERNEL — KPIs

| KPI | Formula | Target |
|-----|---------|--------|
| System uptime | (Total time - Downtime) / Total time | 99.5% |
| API response time | Avg response (p95) | < 500ms |
| Error rate | 5xx / Total requests | < 0.1% |
| Active tenants | Count | Growth tracked |
| Active users | Unique logins (30d) | Growth tracked |
| Notification delivery | Delivered / Sent | > 95% |
