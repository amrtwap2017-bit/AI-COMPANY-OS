# 00-SHARED-KERNEL — Business Capabilities

| ID | Capability | Description |
|----|-----------|-------------|
| SK-01 | Entity Framework | Base entity types with audit, soft delete, tenant isolation |
| SK-02 | Enum Registry | Single source of truth for all domain enums |
| SK-03 | Event Bus | Publish/subscribe for domain events |
| SK-04 | Validation Engine | Shared validation schemas and rules |
| SK-05 | Notification Dispatcher | In-app and email notification delivery |
| SK-06 | Report Generator | PDF, CSV report templating |
| SK-07 | Master Data Management | Currencies, UOM, tax rates, countries |
| SK-08 | Audit Trail | Automatic change tracking on all entities |
| SK-09 | Tenant Isolation | Schema-per-tenant with tenant context |
