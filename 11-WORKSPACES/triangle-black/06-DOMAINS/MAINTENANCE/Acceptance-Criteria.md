# 07-MAINTENANCE — Acceptance Criteria

- [ ] Client can submit service request with category, priority, description, photos
- [ ] Critical requests auto-assigned within 5 minutes
- [ ] SLA timers track response and resolution times
- [ ] Engineer can update status, add notes, mark resolved
- [ ] Client can sign off and rate satisfaction
- [ ] Preventive maintenance schedule with recurring frequencies
- [ ] Warranty claim submitted from service request
- [ ] Maintenance history per project available
