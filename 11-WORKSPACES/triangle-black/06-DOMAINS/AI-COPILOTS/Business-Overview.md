# 10-AI-COPILOTS — Business Overview

## Context

AI Copilots extends the rule-based agents from Phase 5 with more sophisticated capabilities. V1 focuses on practical, high-value automations that integrate with each domain.

## V1 AI Agents

| Agent | Domain | Capability |
|-------|--------|------------|
| Lead Scoring Agent | 01-COMMERCIAL | Score and prioritize leads (Phase 5) |
| Quotation Assistant | 01-COMMERCIAL | Validate margins, suggest pricing |
| NCR Classifier | 02-PROJECT-DELIVERY | Auto-categorize NCRs from description |
| Anomaly Detector | 06-FINANCIAL-CONTROL | Flag unusual invoice patterns |
| Document Classifier | 08-DOCUMENT-MANAGEMENT | Auto-tag uploaded documents |
