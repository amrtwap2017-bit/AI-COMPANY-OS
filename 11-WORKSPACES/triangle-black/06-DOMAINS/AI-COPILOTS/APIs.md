# 10-AI-COPILOTS — API Endpoints

```
GET    /api/v1/ai/agents                    — List agents and status
GET    /api/v1/ai/agents/:name              — Agent detail
POST   /api/v1/ai/agents/:name/execute     — Manually trigger agent
GET    /api/v1/ai/agents/:name/config      — Get agent configuration
PATCH  /api/v1/ai/agents/:name/config      — Update agent config
GET    /api/v1/ai/logs                      — Agent execution logs
GET    /api/v1/ai/logs/:id                  — Log detail
```
