# 06-FINANCIAL-CONTROL — KPIs

| KPI | Target |
|-----|--------|
| DSO (Days Sales Outstanding) | < 45 days |
| DPO (Days Payable Outstanding) | > 45 days |
| Cash conversion cycle | < 0 days |
| AR > 90 days (% of total) | < 5% |
| Invoice accuracy | ≥ 99% |
| Revenue forecast accuracy | ± 10% |
| Project margin variance | ± 5% of quoted margin |
| VAT filing accuracy | 100% |
