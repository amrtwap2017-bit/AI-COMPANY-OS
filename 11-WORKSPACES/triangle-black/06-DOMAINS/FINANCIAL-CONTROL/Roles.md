# 06-FINANCIAL-CONTROL — Roles

| Role | Description |
|------|-------------|
| FINANCE_CLERK | Create invoices, enter supplier invoices, payment recording |
| FINANCE_CONTROLLER | Invoice approval, payment approval, 3-way match oversight |
| FINANCE_MANAGER | Write-offs, credit notes, financial reports |
| PROJECT_MANAGER | View project P&L, cost tracking |
| CLIENT_VIEWER | View invoices, payment history |
