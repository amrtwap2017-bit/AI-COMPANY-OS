# 06-FINANCIAL-CONTROL — Acceptance Criteria

- [ ] Invoice auto-generated from approved milestone
- [ ] VAT 14% auto-applied
- [ ] Invoice lifecycle: draft → sent → paid/written_off

- [ ] Revenue recognized on payment (cash basis V1)
- [ ] Project P&L shows revenue, costs, margin
- [ ] GL entries created for all financial transactions
- [ ] Trial balance report balances (debits = credits)
