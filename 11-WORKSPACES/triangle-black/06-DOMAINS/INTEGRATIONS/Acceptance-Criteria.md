# 11-INTEGRATIONS — Acceptance Criteria

- [ ] SMTP email sending works for notifications, invoices, quotations
- [ ] E-Invoice transforms invoice data to ETA format and submits
- [ ] E-Invoice submission retries 3x on failure
- [ ] Webhooks can be registered for specific event types
- [ ] Webhook delivery retries 3x before disabling
- [ ] Integration logs capture all outbound requests and responses
- [ ] Secrets stored encrypted in configuration
- [ ] CSV import validates data before processing
