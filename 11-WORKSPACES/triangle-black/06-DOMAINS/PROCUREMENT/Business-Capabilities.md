# 03-PROCUREMENT — Business Capabilities

| ID | Capability | Description |
|----|-----------|-------------|
| REQ-01 | Requisition Creation | Site engineer requests materials/services |
| REQ-02 | Requisition Approval | Manager reviews and approves |
| PO-01 | PO Generation | Convert requisition to purchase order |
| PO-02 | PO Approval Workflow | Multi-level approval by value |
| PO-03 | PO Dispatch | Send PO to supplier (email/portal) |
| PO-04 | PO Tracking | Status tracking: sent→confirmed→shipped→received |
| GR-01 | Goods Receipt | Receive and inspect incoming materials |
| GR-02 | Quality Inspection | Check received goods against PO specifications |
| PRP-01 | Procurement Schedule | Project-level procurement timeline |
