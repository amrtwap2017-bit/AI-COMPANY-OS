# 03-PROCUREMENT — Business Overview

## Context

Projects require materials, equipment, and subcontractor services. Procurement manages the request-to-pay cycle: internal requisition → PO → goods receipt → invoice matching.

## Key Workflow

```
Project Need → Create Requisition → Approve → Create PO → Approve PO → Send to Supplier → Receive Goods → Invoice Matching
     ↓              ↓                  ↓          ↓           ↓            ↓               ↓               ↓
  Material      Site Eng         Manager       Proc        Manager      Supplier       Storekeeper     Finance
  Request       submits          approves      Officer     approves      portal         inspects       3-way match
```
