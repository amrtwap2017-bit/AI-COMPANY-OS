# 03-PROCUREMENT — Components

| Component | Purpose |
|-----------|---------|
| RequisitionLineEditor | Add/remove items with qty, spec, unit |
| POApprovalBadge | Status badge with approval level |
| GoodsReceiptForm | Quantity entry per PO line item |
| InspectionResultBadge | Pass/fail/reject per line item |
| ProcurementTimeline | Requisition → PO → Receipt status |
| SupplierSelect | Searchable supplier picker (04) |
| BudgetIndicator | Shows PO against project budget remaining |
