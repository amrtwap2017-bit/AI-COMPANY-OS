# 03-PROCUREMENT — Acceptance Criteria

- [ ] Requisition lifecycle: draft → submitted → approved/rejected
- [ ] Requisition with urgent flag sends notification
- [ ] PO generated from requisition (auto-populate items)
- [ ] PO approval level by value: <50K, 50K-500K, >500K
- [ ] PO status tracks: sent → confirmed → shipped → received
- [ ] Goods receipt records qty received vs PO qty
- [ ] Over-receipt capped at 10%
- [ ] Rejected items tracked with reason
- [ ] Goods receipt updates project budget consumed
- [ ] Goods receipt updates inventory stock levels
