# 03-PROCUREMENT — Roles

| Role | Description |
|------|-------------|
| PROCUREMENT_OFFICER | Create POs, manage suppliers, track orders |
| PROCUREMENT_MANAGER | Approve POs, supplier management, strategy |
| STOREKEEPER | Goods receipt, inspection, inventory updates |
| SITE_ENGINEER | Create requisitions, specify requirements |
| PROJECT_MANAGER | Approve requisitions, project procurement plan |
| FINANCE_CONTROLLER | PO budget check, 3-way matching |
