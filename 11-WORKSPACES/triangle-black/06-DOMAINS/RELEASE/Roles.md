# 99-RELEASE — Roles

| Role | Description |
|------|-------------|
| QA_ENGINEER | Execute tests, log defects, verify fixes |
| QA_MANAGER | Approve test plans, UAT sign-off |
| RELEASE_MANAGER | Manage release pipeline, approvals |
| TRAINER | Create training materials, conduct sessions |
| UAT_TESTER | Execute UAT scenarios (business users) |
