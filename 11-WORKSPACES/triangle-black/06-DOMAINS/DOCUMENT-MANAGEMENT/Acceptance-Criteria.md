# 08-DOCUMENT-MANAGEMENT — Acceptance Criteria

- [ ] User can upload documents to folders with tags/metadata
- [ ] Folder hierarchy supports 5 levels of nesting
- [ ] Version history tracks all changes with uploader and timestamp
- [ ] Allowed file types enforced on upload
- [ ] Full-text search returns results from document names and tags
- [ ] Share links with expiry can be generated
- [ ] Project team sees only authorized documents
- [ ] Document templates available for quotation, contract, report generation
