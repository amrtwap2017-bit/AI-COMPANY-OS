# 08-DOCUMENT-MANAGEMENT — Business Rules

| ID | Rule | Enforcement |
|----|------|-------------|
| DOC-R01 | File size limit: 50MB | Upload validation |
| DOC-R02 | Allowed types: PDF, DOCX, XLSX, DWG, PNG, JPG | Upload validation |
| DOC-R03 | Folder depth: max 5 levels | Validation |
| DOC-R04 | Version number auto-increments | Service logic |
| DOC-R05 | Share links expire after set duration | Cron + validation |
