# 08-DOCUMENT-MANAGEMENT — Workflows

## Document Upload

```
User uploads file → Select folder → Add metadata (tags, description)
    │
    ├── Versions: if file exists with same name → new version
    ├── Permissions: inherit from folder/project
    └── Notification: notify project team of new document
```

## Document Approval (optional workflow)

```
Upload Draft → Request Review → Reviewer Approves → Published
                                    ↓
                              Reject → Revise
```
