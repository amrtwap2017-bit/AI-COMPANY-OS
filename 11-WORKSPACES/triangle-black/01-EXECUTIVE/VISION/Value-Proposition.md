# Phase 00 — Value Proposition

> What makes Triangle Black different and why customers choose it.

## Value Proposition Canvas

### Customer Profile: Hospitality Engineering Company Owner/CEO

| Element | Description |
|---------|-------------|
| **Jobs** | Win contracts, deliver projects on time, manage cash flow, control margins, comply with ETA regulations |
| **Pains** | Slow quotations, missed follow-ups, project delays, supplier issues, cash flow gaps, no visibility into margins |
| **Gains** | Faster sales cycles, predictable margins, on-time delivery, healthy cash flow, data-driven decisions |

### Value Map

| Product/Service | Pain Relievers | Gain Creators |
|-----------------|----------------|---------------|
| Lead Management | Never lose a lead, automated follow-ups | Higher conversion rates |
| Smart Quotation | Margin controls, template-based, approval workflow | Faster quotes, consistent pricing |
| Project Dashboard | Real-time progress, milestone tracking | On-time delivery, client satisfaction |
| Procurement Integration | PO-to-delivery tracking, supplier management | Cost control, no material delays |
| ETA Invoice Integration | Automated submission, compliance guaranteed | Zero fines, faster payment |
| Business Intelligence | Real-time KPIs, margin analysis, dashboards | Informed decisions, profitability insights |

## Unique Differentiators

| Differentiator | Competitors Don't | Triangle Black Does |
|---------------|-------------------|---------------------|
| **Hospitality-specific** | Generic ERP built for manufacturing/retail | Built specifically for hospitality engineering workflows |
| **Revenue-first build** | Build everything poorly | Build revenue-generating features first |
| **Egypt compliance native** | Invoice systems don't support ETA formats | ETA E-Invoice built into financial control |
| **Startup economics** | $500+/mo for comparable ERP | $60-300/mo (equivalent EGP pricing) |
| **Mobile-first field ops** | ERP is desktop-only | PWA with offline support for site surveys |
| **AI-assisted (V2)** | No AI capabilities | Rule-based AI for lead scoring, margin validation |
