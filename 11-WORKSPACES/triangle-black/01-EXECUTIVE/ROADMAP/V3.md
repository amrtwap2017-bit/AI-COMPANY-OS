# V3 Roadmap — Ecosystem

**Theme:** Network effects multiply value
**Duration:** Months 15-24
**Objective:** Turn the platform into a two-sided ecosystem and prepare for regional scale.

## Scope

### Supplier Marketplace (Month 15-18)
| Capability | Description |
|------------|-------------|
| Supplier Self-Service Portal | Suppliers manage profiles, quotes, delivery records independently |
| Auto-RFQ Matching | RFQs automatically distributed to qualified suppliers |
| Bid Comparison | Structured side-by-side quotation comparison |
| Supplier Marketplace | Vetted supplier directory with ratings and categories |
| Direct Procurement | Hotel clients can browse and order from marketplace |

### Benchmarking Engine (Month 18-20)
| Capability | Description |
|------------|-------------|
| Cross-Property Benchmarks | Anonymized KPI comparison across properties |
| Industry Reports | Market intelligence reports derived from aggregated data |
| Cost Indices | Procurement cost benchmarking by category and region |
| Compliance Benchmarks | Brand standard compliance comparison |
| ESG Reporting | Sustainability metrics and reporting |

### AI Agents (Month 20-22)
| Capability | Description |
|------------|-------------|
| Autonomous Procurement | AI agents handle routine procurement with human oversight |
| Predictive Scheduling | AI dynamically adjusts maintenance schedules |
| Anomaly Resolution | AI identifies and resolves operational anomalies |
| Conversational Operations | Full natural language interface for operations |
| AI Supplier Communications | AI drafts and sends supplier communications |

### Platform Expansion (Month 22-24)
| Capability | Description |
|------------|-------------|
| Public API | External developer access, third-party integrations |
| SSO (SAML/OAuth) | Single sign-on for enterprise clients |
| Multi-Tenant Self-Serve | Automated tenant onboarding |
| White-Label Licensing | Platform licensing capability for third-party operators |
| Multi-Currency | Full multi-currency support |

## Key Capabilities Added (Summary)
- Supplier marketplace with automated RFQ distribution
- Cross-property benchmarking for spend, maintenance, compliance
- AI agents for routine procurement decisions
- Public REST API for third-party integration
- Self-serve tenant onboarding
- Single sign-on (SSO) with SAML/OAuth
- White-label platform licensing

## Dependencies
```
V2 stable ──→ V3 expansion
Supplier network maturity ──→ Marketplace launch
Client base size ──→ Meaningful benchmarking
```
