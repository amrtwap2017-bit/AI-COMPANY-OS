# V1 Roadmap — Foundation

**Theme:** Replace chaos with clarity
**Duration:** Months 1-5
**Objective:** Deliver a platform that replaces fragmented, paper-based operations with a structured digital system for the first 3-5 hotel clients.

## V1 Modules

| # | Module | Description | Dependencies |
|---|--------|-------------|--------------|
| 1 | Public Website | Lead generation, company information, service showcase | None |
| 2 | CRM | Leads, opportunities, companies, contacts | Module 1 |
| 3 | Projects | Execution tracking, milestones, deliverables | Module 2 |
| 4 | Quotations | RFQ → proposal → quotation → contract | Module 2 |
| 5 | Client Portal | Transparency, documents, reports | Module 3+4 |
| 6 | Executive Dashboard | Pipeline, revenue, KPIs | All modules |
| 7 | Administration | Users, roles, settings | None (foundation) |

## Phased Timeline

### Phase 0 — Foundation (Month 1-2)
| Module | Deliverables |
|--------|--------------|
| Administration | User management, role-based access, tenant setup |
| Public Website | Company website with service pages, contact form, lead capture |
| CRM Core | Lead management, company records, contact management |
| Authentication | Login, registration, password reset, MFA |

**Milestone M1:** Website live + CRM accepting leads

### Phase 1 — Revenue-Enabling (Month 2-3)
| Module | Deliverables |
|--------|--------------|
| CRM Complete | Opportunity management, pipeline view, activity logging |
| Quotations | Engineering assessment capture, proposal generation, quotation engine, contract creation |
| Client Portal (Basic) | Client login, read-only views, document download |

**Milestone M2:** First quotation generated in system

### Phase 2 — Client-Facing (Month 3-4)
| Module | Deliverables |
|--------|--------------|
| Projects | Project setup, milestone tracking, task assignment, budget tracking |
| Client Portal (Full) | Work order visibility, procurement request submission, project progress, report access |
| Executive Dashboard | Pipeline summary, revenue forecast, KPI widgets, operational health score |

**Milestone M3:** First project tracked with client visibility

### Phase 3 — Polish and Launch (Month 4-5)
| Module | Deliverables |
|--------|--------------|
| Integration Testing | Cross-module workflow testing, data integrity validation |
| Security Audit | Penetration testing, vulnerability remediation |
| Documentation | User guides, admin guides, API docs |
| Deployment | Production environment setup, data migration, go-live |

**Milestone M4:** Platform live with first paying client

## Dependencies
```
Administration (Module 7) ──→ All modules (users, roles, auth)
Public Website (Module 1) ──→ CRM (lead capture)
CRM (Module 2) ──→ Quotations (Module 4) ──→ Projects (Module 3)
All modules ──→ Client Portal (Module 5)
All modules ──→ Executive Dashboard (Module 6)
```

## Key Risks
| Risk | Impact | Mitigation |
|------|--------|------------|
| Scope creep beyond 7 modules | Timeline overrun | Strict scope control; features outside core go to V1.5 |
| Data migration from client systems | Delayed onboarding | Early engagement; data import templates ready before client sign |
| Field engineer mobile adoption | Low platform usage | Arabic UI priority; offline capability; hands-on training |
