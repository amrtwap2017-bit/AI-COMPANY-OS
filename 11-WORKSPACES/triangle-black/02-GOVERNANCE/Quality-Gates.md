# Quality Gates

## Pre-Commit Checklist

- [ ] Document header complete (ID, purpose, version, status)
- [ ] Business value stated
- [ ] Cross-references exist and are correct
- [ ] No contradictions with related documents
- [ ] Consistent terminology (matches Ubiquitous Language)
- [ ] Spelling and grammar checked
- [ ] Follows documentation template

## Pre-Release Checklist

- [ ] All 10 Phases (A-J) reviewed
- [ ] Phase A — Executive Review: business model valid, MVP realistic
- [ ] Phase B — Hospitality Review: reviewed from all 8 hotel stakeholder perspectives
- [ ] Phase C — Product Review: personas, journeys, scope contained
- [ ] Phase D — Architecture Review: DDD correct, boundaries clean, scalable
- [ ] Phase E — Database Review: entities correct, normalized, indexed
- [ ] Phase F — API Review: REST standards, versioning, security
- [ ] Phase G — Infrastructure Review: Docker, Nginx, backups, monitoring
- [ ] Phase H — Cost Optimization: every component justified, budget $25-40/mo
- [ ] Phase I — MVP Reduction: only revenue-generating features in V1
- [ ] Phase J — AI Readiness: data collected for future AI, architecture supports it
