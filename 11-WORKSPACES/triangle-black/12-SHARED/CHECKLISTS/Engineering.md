# Engineering Delivery Checklist

## Pre-Work Order
- [ ] Asset registered in platform with correct details
- [ ] Asset QR code affixed and scanned
- [ ] Work order category and priority correctly assigned
- [ ] SLA defined based on priority
- [ ] Required checklists attached to work order
- [ ] Parts and materials availability confirmed
- [ ] Engineer skill match confirmed
- [ ] Engineer notified with all required details

## Work Execution
- [ ] Engineer acknowledged assignment
- [ ] Engineer arrived at location (QR scanned or located)
- [ ] Pre-work photos taken (if applicable)
- [ ] Work performed per standard procedure
- [ ] Checklist items completed and signed
- [ ] Parts/materials consumption logged
- [ ] Post-work photos taken
- [ ] Engineer completed and signed work order

## Quality Check
- [ ] Work order in quality review queue
- [ ] Photos reviewed for work quality
- [ ] Checklist completion verified
- [ ] Materials usage verified against estimate
- [ ] Physical inspection conducted (critical/high priority)
- [ ] Quality result recorded (Pass / Fail)
- [ ] Re-work assigned if failed

## Completion
- [ ] Work order closed in system
- [ ] Asset maintenance history updated
- [ ] Client notified (for high-priority work)
- [ ] Customer satisfaction survey sent (if applicable)
- [ ] Time logged against work order
- [ ] Cost recorded against work order budget

## Preventive Maintenance
- [ ] PM schedule defined and loaded in platform
- [ ] Asset linked to PM schedule
- [ ] Auto-generation of PM work orders verified
- [ ] Compliance checklists per PM type created
- [ ] Overdue PM monitoring active
- [ ] Monthly compliance report generated
