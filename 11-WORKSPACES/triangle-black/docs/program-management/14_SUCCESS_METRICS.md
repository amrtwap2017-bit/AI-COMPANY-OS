# Program Success Metrics

| Category | KPI | Initial target at GA |
|---|---|---|
| Technical | deployment frequency, change failure rate, MTTR | weekly+ safe releases, <10% failure, <60 min MTTR. |
| API | contract compatibility, p95 latency, error rate | 100% registered routes; 99.9% success; agreed p95 by class. |
| Platform | availability, tenant isolation incidents, provisioning time | 99.9% core availability; zero isolation incidents; tenant <30 min. |
| Quality | escaped defects, test pass rate, type/lint debt | zero release-blocking defects; deterministic green gates. |
| Security | critical findings, secret exposure, access review completion | zero critical open; no committed secrets; 100% quarterly access review. |
| Data | migration reconciliation, data quality, backup restore success | 100% reconciliation; restore drill pass. |
| Workflow | SLA compliance, approval cycle, transition failures | measurable improvement per migrated workflow; no unowned transitions. |
| Business | lead conversion, project variance, stockouts, MTTR, collections | baseline first; quarterly improvement targets by capability owner. |
| AI | citation coverage, acceptance, quality, cost per decision, unsafe actions | 100% evidence for governed answers; zero unauthorized side effects. |
| Operations | alert detection, queue age, SLO burn, incident recurrence | alert within SLO; no silent failure paths. |
| Developer experience | setup time, PR lead time, build time, flaky tests | reproducible setup; declining PR cycle/flakiness. |
| SaaS | tenant adoption, feature flag success, usage/AI credits | configurable tenant provision and metered usage. |
