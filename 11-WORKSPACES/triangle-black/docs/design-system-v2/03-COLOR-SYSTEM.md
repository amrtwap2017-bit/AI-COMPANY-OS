# Color System

## Core Rule

Bronze (#B9924C) is the BRAND ACCENT — not the UI color.

Use bronze for:
- Selected navigation item
- Primary CTA button
- Focus ring
- Premium KPI emphasis
- Brand identity moments

Never use bronze for:
- Success states
- Warning states
- Error states
- Information states
- Generic status

## Status Color System

SUCCESS: #22C55E on #F0FDF4 background
Use for: completed, healthy, operational, approved, received

WARNING: #F59E0B on #FFFBEB background
Use for: pending, at-risk, overdue, needs attention

ERROR: #EF4444 on #FEF2F2 background
Use for: failed, rejected, critical, breach

INFO: #3B82F6 on #EFF6FF background
Use for: informational, scheduled, neutral status

NEUTRAL: #6B6B66 on #F4F4F2 background
Use for: draft, inactive, archived, unknown

## Contrast Requirements

All text on surfaces: minimum 4.5:1 contrast ratio
Large text/headers: minimum 3:1 contrast ratio
Interactive focus: 3:1 against adjacent colors
Status indicators: never rely on color alone — always pair with icon or label

## Sidebar Color Logic

Sidebar: #1C1C1E (neutral graphite)
- Inactive text: #9B9B96
- Active text: #F9F9F7
- Active background: rgba(185,146,76,0.12)
- Active accent: #B9924C left border
- Hover: rgba(255,255,255,0.06)

This creates clear information hierarchy:
Dark graphite navigation = command layer
Light cream content = operational workspace

## Executive Dashboard Colors

Executive may use darker surfaces but must maintain:
- White/cream typography
- Semantic status colors unchanged
- Bronze accent for emphasis only
- Never decorative color use
