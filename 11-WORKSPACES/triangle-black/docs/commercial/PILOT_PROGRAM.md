## 30-Day Pilot Timeline

### Week 1 — Discovery + Onboarding (Days 1-7)

**Day 1-2: Kickoff**
- Engineering assessment kickoff call
- Current state data collection
- Platform access provisioning (< 2 minutes via self-service)

**Day 3-5: Data Import**
- Asset register import (CSV)
- Supplier list import
- Historical work order data import
- PM plan configuration

**Day 6-7: Baseline Capture**
- KPI snapshot: WO completion rate, PM compliance, supplier scores
- Risk assessment: identify top 5 asset risks
- Cost baseline: total operational spend

---

### Week 2 — Platform Configuration (Days 8-14)

- SLA configuration per property type
- Work order workflow setup
- Intelligence engine calibration
- User onboarding (managers, technicians)
- First AI Director advisory review

---

### Week 3 — Operational Monitoring (Days 15-21)

- Live work order management
- PM compliance tracking
- Supplier performance scoring
- Backlog analysis
- Weekly intelligence report

---

### Week 4 — Analysis + ROI (Days 22-30)

- KPI snapshot: post-intervention measurement
- Before/after delta analysis
- Cost avoidance calculation
- Recommendation review
- Executive report preparation
