# 20-Operations-Manual — Standard Operating Procedures

This section contains all Standard Operating Procedures (SOPs) for Triangle Black's core business functions. Each SOP defines the process flow, actors, inputs, outputs, business rules, and KPIs for a given operational domain.

## Contents

| File | Description |
|------|-------------|
| Sales-SOP.md | Lead handling, CRM updates, follow-up cadence, closing process |
| Purchasing-SOP.md | Requisition creation, approval routing, PO issuance, delivery tracking, invoice matching |
| Engineering-SOP.md | Work order lifecycle, task assignment, quality checks, completion verification |
| Project-SOP.md | Project setup, milestone tracking, progress reporting, change orders, handover |
| Admin-SOP.md | User onboarding, role assignment, system configuration, audit reviews |
| Finance-SOP.md | Invoicing, payment collection, supplier payment, budget tracking, reconciliation |

## SOP Structure

Each SOP follows this structure:
1. **Purpose** — What the SOP covers
2. **Scope** — Applicable departments, roles, and systems
3. **Actors** — Roles involved in the process
4. **Process Flow** — Step-by-step procedure
5. **Business Rules** — Policies, thresholds, constraints
6. **Inputs / Outputs** — Required inputs and produced outputs
7. **KPIs** — Performance indicators for the process
8. **Exceptions** — Known edge cases and how to handle them
