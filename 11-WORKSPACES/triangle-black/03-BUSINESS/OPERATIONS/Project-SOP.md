# Project SOP — Standard Operating Procedure

## Purpose
Define the standard process for managing engineering projects from initiation through handover, ensuring consistent governance, milestone tracking, and client satisfaction.

## Scope
All capital projects, renovation projects, pre-opening projects, and major engineering initiatives managed by Triangle Black.

## Actors
- Project Manager — owns project delivery
- Project Coordinator — supports scheduling and documentation
- Director of Engineering — approves scope and budget changes
- Client Representative — approves milestones and sign-offs
- Contractor / Subcontractor — executes project work
- Finance Controller — monitors project budget

## Process Flow

### 1. Project Setup
| Step | Action | Owner |
|------|--------|-------|
| 1.1 | Project created in platform from signed contract | Project Manager |
| 1.2 | Scope, deliverables, exclusions defined and approved | Project Manager + Client |
| 1.3 | Budget allocated by cost category | Finance Controller |
| 1.4 | Timeline with key milestones defined | Project Manager |
| 1.5 | Team assigned (internal staff + contractors) | Director of Engineering |
| 1.6 | Project folder created with document templates | Project Coordinator |
| 1.7 | Kickoff meeting held with all stakeholders | Project Manager |

### 2. Milestone Tracking
| Step | Action | Owner |
|------|--------|-------|
| 2.1 | Each milestone has defined: description, owner, start date, end date, deliverables, acceptance criteria | Project Manager |
| 2.2 | Milestone progress updated weekly (or daily for critical path) | Project Manager |
| 2.3 | Progress evidence uploaded: photos, reports, sign-offs | Project Coordinator |
| 2.4 | Milestone completion submitted for client approval | Project Manager |
| 2.5 | Client approves milestone → next milestone activated | Client |

### 3. Progress Reporting
| Report | Frequency | Audience | Contents |
|--------|-----------|----------|----------|
| Daily Report | Every working day | Project Team | Tasks completed today, tasks for tomorrow, issues, safety notes |
| Weekly Report | Every Monday | Client + Management | Milestone progress, budget vs actual, photos, risks, next week plan |
| Monthly Report | First of month | Executive | Overall progress, financial summary, change orders, forecast |
| Completion Report | Project close | Client + Archive | Final deliverables, lessons learned, warranties, handover docs |

### 4. Change Orders
| Step | Action | Owner |
|------|--------|-------|
| 4.1 | Change request logged by any stakeholder | Stakeholder |
| 4.2 | Impact assessment: scope, cost, schedule | Project Manager |
| 4.3 | Change order document prepared | Project Manager |
| 4.4 | Approved by Director of Engineering (internal) | Director of Engineering |
| 4.5 | Approved by Client (cost/schedule impact) | Client |
| 4.6 | Change order filed and project baselines updated | Project Coordinator |
| 4.7 | No work on change begins without signed change order | All |

### 5. Handover
| Step | Action | Owner |
|------|--------|-------|
| 5.1 | Snag list completed (punch list of outstanding items) | Project Manager |
| 5.2 | All snags cleared and signed off | Project Manager + Client |
| 5.3 | Handover document package compiled | Project Coordinator |
| 5.4 | O&M manuals, warranties, as-built drawings collected | Project Coordinator |
| 5.5 | Training completed (if applicable) | Project Manager |
| 5.6 | Project completion certificate signed by Client | Client |
| 5.7 | Final financial reconciliation completed | Finance Controller |
| 5.8 | Project archived in platform | Project Coordinator |
| 5.9 | Lessons learned session held | Project Manager |

## Business Rules
- No work without a signed contract and approved project setup
- Change order required for any scope, cost, or schedule deviation
- Milestone gates require client sign-off before proceeding
- Budget variance > 10% triggers mandatory review
- Projects overdue by > 20% of original timeline require operations director review

## Inputs / Outputs
| Inputs | Outputs |
|--------|---------|
| Signed contract | Project plan |
| Scope of work | Milestone completion reports |
| Budget allocation | Change orders |
| Client requirements | Handover documentation |
| Contractor agreements | Lessons learned report |

## KPIs
| KPI | Target | Frequency |
|-----|--------|-----------|
| On-time completion | > 85% of milestones | Monthly |
| On-budget completion | Within 10% of budget | Per project |
| Change order cycle time | < 5 business days | Monthly |
| Client satisfaction score | > 4.5 / 5 | Per project |
| Snag count at handover | < 10 items | Per project |
| Lessons documented | 100% of projects | Per project |

## Exceptions
- Emergency projects: Simplified setup within 24 hours, full documentation within 5 days
- Small projects (< EGP 50,000): Lightweight process — no monthly reporting, no formal lessons learned
- Fixed-price contracts: Change order process still applies for any deviation
