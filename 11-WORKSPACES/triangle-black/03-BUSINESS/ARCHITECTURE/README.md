## How to Use This Folder

- **New team members** start with Business-Model.md and Services.md
- **Sales and BD** reference Go-To-Market.md, Customer-Personas.md, and Pricing.md
- **Strategy and leadership** use SWOT.md, Risk-Register.md, Growth-Strategy.md, and Expansion-Strategy.md
- **Partnership leads** work from Partnership-Strategy.md
- **All documents** feed into the Revenue-Architecture.md for financial planning

All documents are living assets. Update status to "Reviewed" or "Final" as each reaches its maturity milestone.
