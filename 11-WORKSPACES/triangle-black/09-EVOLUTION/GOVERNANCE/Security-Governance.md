## Security Principles

1. **Security by design** — Security built in, not bolted on
2. **Least privilege** — Minimum access for minimum time
3. **Defense in depth** — Multiple layers of security
4. **Assume breach** — Design for breach scenario
5. **Continuous improvement** — Security evolves with threats
6. **Shared responsibility** — Everyone owns security
