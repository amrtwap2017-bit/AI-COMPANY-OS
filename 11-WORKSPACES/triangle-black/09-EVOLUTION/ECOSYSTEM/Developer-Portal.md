## Documentation Standards

| Standard | Requirement |
|----------|-------------|
| API docs | OpenAPI 3.1, interactive sandbox |
| Language | English (primary), Arabic (H2) |
| Format | Markdown + code blocks |
| Examples | Every endpoint has request/response |
| Errors | Every error code documented |
| Versioning | API version in URL + docs |
