## Onboarding Phases

```
DAY 1: SETUP                              DAY 2-3: CONTEXT
├── Dev environment setup                 ├── Architecture overview
├── Access provisioning                   ├── Domain overview
├── Intro to codebase                    ├── Key workflows
├── Team introduction                    ├── Code review participation
└── Onboarding buddy assigned            └── First PR (docs, test)

WEEK 1-2: CONTRIBUTION                    WEEK 3-4: INDEPENDENCE
├── First feature (pair)                 ├── Independent feature
├── Bug fix contributions                ├── On-call shadowing
├── Test writing                         ├── Architecture discussions
├── CI/CD pipeline understanding         └── Onboarding feedback
└── On-call training
```

## Onboarding Checklist

| Item | Owner | Timeline | Verification |
|------|-------|----------|--------------|
| Dev environment setup | Developer + buddy | Day 1 | App runs locally |
| Access to all systems | Engineering lead | Day 1 | All logins work |
| Architecture overview | CTO | Day 2 | Can explain key components |
| Domain overview | Product lead | Day 2 | Can explain key domains |
| First PR merged | Developer | Day 5 | PR merged |
| On-call training | DevOps lead | Week 2 | Shadowed on-call shift |
| First feature shipped | Developer | Week 3 | Feature in production |
| Onboarding survey | Developer | Week 4 | Feedback collected |
