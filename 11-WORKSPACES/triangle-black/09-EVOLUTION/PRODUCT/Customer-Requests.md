## Request Intake

| Channel | Description | Response SLA | 
|---------|-------------|--------------|

| NPS comments | Feedback in NPS surveys | 1 week |

## Request Lifecycle

```
Submit ──► Triage ──► Evaluate ──► Decide ──► Communicate ──► Deliver
  │         │           │            │           │              │
Customer  Product    Feasibility  Approve/   Close the     Release
submits   manager   + value     Defer/      loop with     notes
request   reviews   assessment  Decline     customer
```
