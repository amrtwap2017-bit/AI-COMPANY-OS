| Source | Input |

## Release Cadence

| Release | Timing | Scope | Customers |
|---------|--------|-------|-----------|
| V1.0 | Phase 5-6 | Core PMS, reservations, housekeeping, procurement | MVP pilot (3) |
| V1.1 | Phase 9 | Revenue management, reporting, commercial | 5-10 |
| V1.2 | H1 Q1 | AI copilots (support, ops), BI dashboards, workflow automation | 10-20 |
| V1.3 | H1 Q2 | Premium support, training, channel manager | 20-30 |
| V1.4 | H1 Q3 | Mobile app, partner portal, advanced analytics | 30-50 |
| V1.5 | H1 Q4 | Public API, ecosystem marketplace, GCC localization | 50-100 |
| V2.0 | H2 | Multi-region, predictive AI, self-optimizing | 100-300 |

## Evolution Principles

- Backward compatible for 6 months
- Customer data migration path always provided
- Major version = breaking changes
- Minor version = new features, no breaking changes
- Patch = bug fixes only
- LTS releases supported for 12 months
