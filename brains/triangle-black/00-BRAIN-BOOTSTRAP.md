## What Is This Project
Triangle Black is a full-stack commercial CRM + Service Operations platform
for a hotel engineering services company in Egypt.

## Technology Stack
- Backend:     FastAPI (Python 3.12), SQLAlchemy, PostgreSQL 17 + pgvector
- Frontend:    Next.js 16.2.10 App Router, TypeScript, Tailwind CSS, React Query
- Auth:        JWT (python-jose) + bcrypt
- DB:          ai-postgres Docker container, port 5432
- Package mgr: uv (NEVER pip)
- Shell:       zsh on WSL Ubuntu
