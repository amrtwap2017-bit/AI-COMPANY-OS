================================================================
BUSINESS CONTEXT
================================================================

Triangle Black operates as a hotel engineering contractor in Egypt.
Revenue comes from:
  1. Maintenance contracts (monthly EGP per hotel)
  2. Supply/procurement margin (buy materials, charge hotels)
  3. Project contracts (HVAC install, MEP, civil works)

Core operational cycle:
  REQUEST IN (WhatsApp/Email/Site) 
  -> CHECK INVENTORY (do we have the part?)
  -> IF YES: dispatch technician with part
  -> IF NO: find best vendor, create PR/PO, procure, then dispatch
  -> EXECUTE work order
  -> CLOSE and invoice client

The AI brain should:
  1. Read incoming requests (any channel)
  2. Parse what is needed (part + quantity + urgency + location)
  3. Check warehouse stock automatically
  4. If available: create WO + assign best technician
  5. If not available: find best vendor + create PR + notify team
  6. Learn from every cycle to get smarter
